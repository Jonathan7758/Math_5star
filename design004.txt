# 第五部分：代码质量问题 (审计中发现)

## 5.1 AchievementToast 接口冗余
- 文件: `frontend/src/components/gamification/AchievementToast.tsx:11-17`
- 问题: `achievementName` 和 `achievementDesc` 作为可选 props 定义，但 QuizPage 调用时从未传入。组件内部有 `ACHIEVEMENT_INFO` 字典作为兜底，这两个 props 形同虚设。
- 建议: 要么移除这两个 props，要么在所有调用处传入实际值。

## 5.2 DailySummaryPage: correctCount 计算在边缘情况可能不准确
- 文件: `frontend/src/pages/QuizPage.tsx:39`
- 问题: `correctCount` 是 `questionCount - (feedback && !feedback.is_correct ? 1 : 0)`，但在 hearts=0 跳转时，最后一次错误也算入 questionCount，导致传递给总结页的数据中 correctCount 可能比真实值少 1。
- 建议: 改为在答题过程中维护独立的 correctCount 状态变量。

## 5.3 精灵 reaction 只在 QuizPage 更新
- 文件: `frontend/src/pages/QuizPage.tsx:80`
- 问题: SpriteDisplay 的 reaction 仅在 QuizPage 中根据 rewards API 返回值设置。HomePage 固定 reaction="idle"，DailySummaryPage 固定 reaction="celebrate"。精灵在首页无入场动画或根据时间的交互变化。
- 建议: 精灵组件内聚 reaction 逻辑，根据上下文自动选择合适状态。

## 5.4 explanations.json 缺失
- 文件: `backend/config.py` (引用路径)
- 问题: config 中配置了 explanations.json 路径但文件不存在。TeachingAgent 的 explain 方法可能依赖此文件。
- 建议: 创建 explanations.json 或确保 TeachingAgent 在文件缺失时降级处理。
