## PRIORITY 1: design009 Phase 2 — New Quiz Interaction Types (1-2 weeks)

All 6 types are unimplemented. Current: only numeric-input + multiple-choice.

### 1.1 Shooting-style MC (攻靶选择)
Options displayed as targets (floating circles/objects). Click = fire projectile at answer.
Particle hit effect on correct target. Most feasible to implement first.

### 1.2 Drag-to-Order (拖拽排序)
Show shuffled solution steps. Drag to arrange in correct order. Submit order for verification.
Quiz bank needs "order" type questions added.

### 1.3 Number-line Slider (数轴滑块)
Display number line axis. Drag marker to answer position. Need for fraction/comparison questions.

### 1.4 Line-Matching (连线匹配)
Left column: expressions. Right column: results. Draw lines to connect matches.
Quiz bank needs "match" type questions.

### 1.5 Geometry Dragging (几何拖拽)
Drag angles/edges/vertices to correct positions. Canvas-based.
Most complex — depends on geometry KP questions.

### 1.6 Spinning Wheel (转盘)
Dial pointer to correct answer. Rotary interaction. Gamification-heavy.

## PRIORITY 1: design009 Phase 3 — Animation System Upgrade (1 week)

All 5 advanced animations unimplemented. Current animations: CSS keyframes only.

### 3.1 Skill Cast Animation
Correct answer: sprite shoots energy ray → hits monster target → explosion particles.
Requires: Canvas overlay, flame/beam rendering, particle burst on impact.

### 3.2 Damage Reaction
Wrong answer: screen flash red (50ms) + Camera2D shake + heart shatter SVG animation.
Heart UI element: cracks → splits → falls off.

### 3.3 Level-Up Transformation
Sprite full-body golden glow + morphology change (next stage) + spin 360°.
Combine: CSS glow filter + CSS transform rotate + sprite stage swap at midpoint.

### 3.4 Stage Complete Settlement Panel
Fireworks (exists) + falling star particles + settlement panel slide-up from bottom.
Panel: XP earned, coins, new achievements unlocked, combo streak preserved.

### 3.5 Treasure Chest Open
Shake animation (CSS wiggle) → opens → golden light rays (CSS radial-gradient) → item/card pops out with scale-up.
Triggered on: milestone achievements, daily goal complete, level-up.
