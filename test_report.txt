## UX Assessment
============================================================

### P0.1: Storyteller Frontend Integration
- Backend: /api/exercise/story endpoint generates per-question themed stories via DeepSeek LLM
- Backend: /api/exercise/themes returns 8 themes with icons and Chinese names
- Frontend: QuizPage has horizontal scrollable theme selector chips (随机 + 8 themes)
- Frontend: QuestionCardEnhanced renders themed dialogue bubble with story_question text
- Frontend: 8 theme visual styles mapped (gradient + border + accent color per theme)
- Theme-to-knowledge-point mapping: random by default, user-selectable
- Cache: storyteller_agent.py caches generated stories per question_id+theme

### P0.2: MathJax Rendering
- MathJax v3 CDN script (tex-svg) added to index.html
- MathText component: useEffect calls window.MathJax.typesetPromise() on container ref
- Fallback: if MathJax unavailable or text has no LaTeX, uses regex-based styled spans
- Global type declaration for window.MathJax to satisfy TypeScript
- No npm import required; CDN script loads async

### Known Issues / Limitations
1. Flutter app has only 5 screens; missing achievements, skin shop, daily summary, onboarding, knowledge graph, stats charts, share card, etc. (10+ features missing vs React)
2. Canvaskit files not uploaded to server; Flutter web may fall back to HTML renderer
3. 1 pre-existing backend test failure: test_submit_equivalent_answer (SymPy equivalence check edge case)
4. Venv not created; backend uses system Python with --break-system-packages
5. Storyteller LLM calls may timeout when DeepSeek API key not configured; falls back to icon prefix
6. MathJax typesetting is async; brief flash of unstyled math possible on slow connections
