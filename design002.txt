# 一、用户体验深度分析（12-14岁 / Y8-Y9）

## 1.1 用户画像

### 学生端 — 小明（12岁，Y8，ESF学生）
- **注意力时长**：单次 5–15 分钟
- **数学水平**：Y8中游偏下，乘法口诀不熟练，有理数运算是弱点
- **心理特征**：
  - 对数学有焦虑感，觉得"自己数学不好"
  - 喜欢游戏（Roblox、Minecraft），愿意为游戏花时间
  - 在意即时反馈，不喜欢"做了一堆题才知道对错"
  - 对"大人说教式"辅导有抵触
  - 喜欢收集、养成类玩法（宠物、皮肤、成就）
- **设备**：iPhone 或 安卓手机为主；偶尔用 iPad
- **使用场景**：放学后、晚饭前、睡前；地铁/巴士通勤中

### 家长端 — 张女士（38岁，非数学专业）
- **核心诉求**：知道孩子哪块薄弱，不用自己辅导
- **看板使用频率**：每周1-2次，每次3-5分钟
- **关键决策**：是否按系统建议安排孩子学习路径
- **设备**：手机 + 电脑均可

## 1.2 Duolingo式快速奖励模型分析

### Duolingo成功要素（适配数学学习）

| Duolingo机制 | 数学版适配 | 设计要点 |
|-------------|-----------|---------|
| **答题→即时反馈** | 提交答案 → 0.3秒内动画+音效反馈 | 正确: 绿色对勾+粒子+精灵跳跃；错误: 温柔摇头+引导文字 |
| **连胜(Streak)** | 连续学习天数；连续答对题数 | 双重连胜：日连胜(鼓励坚持) + 题连胜(鼓励专注) |
| **XP与等级** | 每做一题得 XP，累积升级 | XP可视化条，升级弹出动画 |
| **💎宝石/金币** | 数学星币(Star Coins) | 用于兑换皮肤、道具 |
| **❤️爱心/生命** | 学习专注力(每局3心) | 错3次→本次练习结束，12小时后恢复 |
| **每日目标** | 可自选 5/10/15分钟 | 显示完成环，达标记为✅ |
| **排行榜** | 可选：与"自己昨天"竞赛 | 不引入社交压力，避免比较焦虑 |
| **宝箱/奖励** | 每次升级开宝箱 | 包含皮肤碎片、星币、保护盾 |
| **成就徽章** | 完美主义/速算达人/连击王 | 50+可收集成就 |
| **声音设计** | 答对: 清脆叮咚；答错: 柔和低音；连击: 音阶上升 | 用声音建立条件反射 |

### 关键设计原则（区别于Duolingo）

1. **不允许跳过基础**：知识图谱驱动的路径不可绕行，确保补漏优先
2. **错误比正确更"值钱"**：错误触发渐进式提示 → 诊断价值 → 学习深度
3. **不惩罚不知道**：错误不扣太多分，保护学习信心
4. **妈妈看得懂**：所有界面文案用家长能看懂的语言

## 1.3 学习流程 UX 设计（一屏一题闯关式）

### 完整用户旅程

```
打开APP → 精灵问候（今日目标环展示）→ 开始学习
    ↓
[诊断模式]（首次/定期触发）
    → 随机抽取知识图谱各节点的代表题
    → 每道题限时/不限时
    → 答错不中断，继续下一题
    → 全部答完后生成断点报告
    → 精灵： "找到啦！你的有理数需要补一补～"
    ↓
[学习模式]（日常使用）
    → 系统根据规划路径推送题目
    → 一屏一题：
        ├─ 顶部：精灵（缩小到侧边，根据对错做表情）
        ├─ 中间：题目区域
        ├─ 底部：答题区（输入框/选项按钮）
        └─ 反馈层（覆盖动画，0.5秒后消失）
    → 答对：绿光扫过 + 精灵竖大拇指 + XP数字飞出 + 连击计数+1
    → 答错(第1次)：精灵歪头 + "再想想？" + 不扣心
    → 答错(第2次)：精灵捧书 + 渐进提示1
    → 答错(第3次)：完全解析 + 心-1
    → 3心耗尽：本次学习结束，鼓励"休息一下，明天继续！"
    ↓
[每日结束]
    → 精灵总结：今日XP、最高连击、连胜保持
    → 每日目标完成环动画
    → 若触发进化/升级 → 精灵变身动画
    → 推送："明天见，连胜等你守护！"
```

### 微交互规范

| 交互 | 动画时长 | 效果 |
|-----|---------|------|
| 答对反馈 | 0.3s | 绿色边框脉冲 + 精灵跳跃 + 星子粒子 |
| 答错反馈 | 0.3s | 橙色边框闪烁 + 精灵歪头 |
| XP获得 | 0.5s | XP数字从题目区飞到顶部XP条 |
| 升级 | 1.2s | XP条灌满→爆炸→新等级浮现 |
| 连击 | 即时 | 连击数字变大、变色（3连击:蓝，5连击:紫，10连击:金）|
| 精灵进化 | 2.0s | 全屏光效→包裹精灵→新形态展现 |
| 每日目标达成 | 1.0s | 环填满→对勾→烟花粒子 |

## 1.4 移动端适配要点

- **触控区域**：最小 44×44px（iOS标准）/ 48×48px（Android标准）
- **单手操作**：核心操作区在屏幕下半1/3
- **横屏支持**：题目+精灵左右分栏
- **PWA离线**：静态资源全缓存，做题记录本地暂存，联网后同步
- **推送通知**：每日学习提醒（可选时段），连胜即将中断提醒
- **深色模式**：支持，减少晚间学习眼部疲劳

# 二、成长精灵形象设计

## 2.1 精灵世界观
**名字**：启小星 (Qi Xiao Xing)
**物种**：数学星灵 — 来自知识星云的几何生命体
**性格**：好奇、调皮、从不批评、热爱数学
**口头禅**：
- "数学像星星一样，一颗一颗点亮！"
- "错一次，离正确又近一步～"
- "哇！你比昨天更厉害了！"

## 2.2 五阶段进化体系

### Stage 0：星尘 (Star Dust) — 初始形态
- **外观**：一团跳动的金色星光粒子团，直径约60px
- **动作**：缓慢旋转，偶尔闪烁，像一个害羞的小火苗
- **解锁条件**：首次登录
- **能力**：简单欢迎，引导诊断
- **配音调性**：清脆、好奇

### Stage 1：星芽 (Star Sprout) — 第7天解锁
- **外观**：从星尘中长出几何叶片(三角形/六边形)，高约80px
- **动作**：叶片轻微摇摆，偶尔冒出+、−、×、÷符号
- **解锁条件**：完成首次诊断 + 累计学习≥3天
- **能力**：展示"今日目标环"，出题时叶片发光
- **配音调性**：活泼、有点小骄傲

### Stage 2：星苗 (Star Seedling) — 第21天解锁
- **外观**：长成小型多边形树，枝叶由几何形状构成（正方体、圆柱体），高约120px
- **动作**：枝干微微摆动，果实是发光的小数学符号
- **解锁条件**：掌握≥10个知识点 + 7天连胜
- **能力**：答错时"掉落"提示果实（渐进提示）
- **配音调性**：温暖、朋友感

### Stage 3：星光 (Star Light) — 第60天解锁
- **外观**：悬浮的几何晶体生物，周围环绕轨道式旋转的数学符号（π、√、∑等），高约150px
- **动作**：优雅旋转，轨道符号随连击数加速
- **解锁条件**：掌握≥30个知识点 + 30天总学习 + 最高连胜≥14天
- **能力**：偶尔出"挑战题"（答对双倍XP）
- **配音调性**：自信、有点小调皮

### Stage 4：启明星 (Morning Star) — 终极形态
- **外观**：五角星核心 + 星座连线图案 + 光芒粒子效果，高约180px
- **动作**：稳定悬浮，光芒随呼吸频率明暗变化
- **解锁条件**：掌握所有Y7-Y9知识点（~100个）+ 累计学习≥100天
- **能力**：解锁"星图模式"——可查看自己掌握的知识图谱全景
- **配音调性**：庄重又亲切，像陪伴已久的老师

## 2.3 荣誉徽章体系（50+徽章）

### 分类

| 🎯 精准 | 百发百中 / 完美主义 / 零失误 | 10/30/50题连对 |
| ⚡ 速度 | 闪电侠 / 思维风暴 | 限时题全对 |
| 📚 学识 | 有理数大师 / 几何探索者 / 代数征服者 | 某领域全知识点掌握 |
| 🎖 毅力 | 百题斩 / 千题破 | 累计做题数量 |
| 🌟 特殊 | 启明星之约 / 早起鸟 / 夜猫子 | 特定行为 |

# 三、分阶段版本规划 (v0.1 → v2.0)

## v0.1 — 骨架搭建（第1-2周）

### 目标
项目骨架可用，前后端能通信，知识图谱可加载。

### 交付物
| 模块 | 内容 |
|------|------|
| 后端脚手架 | FastAPI app + CORS + 日志；SQLite + SQLAlchemy 模型定义；`/api/health` |
| 知识图谱引擎 | NetworkX加载 knowledge_graph.json v0.1（~20个节点）；BFS/DFS工具函数 |
| 前端脚手架 | React + Vite + Tailwind + vite-plugin-pwa；路由框架，移动端适配基础布局 |
| 基础题库 | quiz_bank.json v0.1（每个知识点2道题，手动编写，SymPy验证） |
| CI/CD | GitHub Actions：lint (ruff + eslint) + test (pytest + vitest) |

### 不包含
- 任何 Agent 业务逻辑
- 精灵UI
- 家长看板

---

## v0.2 — 诊断闭环（第3-4周）

### 目标
首次完成"答题→诊断→出报告"闭环。

### 交付物
| 模块 | 内容 |
|------|------|
| 诊断Agent | BFS根因分析；错误频次聚合；断点优先级排序 |
| 学生答题界面 | 一屏一题基础版（无精灵）；选项按钮+ 对错反馈文字 |
| API | `POST /api/diagnose`, `GET /api/exercise/next`, `POST /api/exercise/submit` |
| 题库扩充 | quiz_bank扩至每知识点5题（含L1/L2） |
| 诊断报告页 | 断点列表+知识点名称+简单解释文字（无图形） |
| 测试 | 诊断Agent单元测试(15+)；API集成测试(8+) |

### 不包含
- 教学/规划/激励Agent
- 精灵
- 家长看板

---

## v0.3 — 学习闭环（第5-6周）

## 4.2 数据模型

### SQLite 表结构

```sql
-- 学生表
CREATE TABLE student (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    total_xp INTEGER DEFAULT 0,
    level INTEGER DEFAULT 1,
    star_coins INTEGER DEFAULT 0,
    current_streak_days INTEGER DEFAULT 0,
    longest_streak_days INTEGER DEFAULT 0,
    last_active_date DATE,
    daily_goal_minutes INTEGER DEFAULT 10
);

-- 答题记录
CREATE TABLE answer_record (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL,
    question_id TEXT NOT NULL,
    knowledge_point_id TEXT NOT NULL,
    student_answer TEXT NOT NULL,
    is_correct BOOLEAN NOT NULL,
    time_spent_seconds REAL,
    hint_level_used INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES student(id)
);

-- 知识点掌握度
CREATE TABLE mastery (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL,
    knowledge_point_id TEXT NOT NULL,
    mastery_score REAL DEFAULT 0.0,  -- 0.0 ~ 1.0
    total_attempts INTEGER DEFAULT 0,
    correct_attempts INTEGER DEFAULT 0,
    last_practiced_at TIMESTAMP,
    UNIQUE(student_id, knowledge_point_id),
    FOREIGN KEY (student_id) REFERENCES student(id)
);

-- 精灵状态
CREATE TABLE sprite_state (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL UNIQUE,
    stage INTEGER DEFAULT 0,         -- 0~4
    skin TEXT DEFAULT 'classic_gold',
    accessory TEXT DEFAULT NULL,
    total_learning_days INTEGER DEFAULT 0,
    FOREIGN KEY (student_id) REFERENCES student(id)
);

-- 成就
CREATE TABLE achievement (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL,
    achievement_key TEXT NOT NULL,
    unlocked_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(student_id, achievement_key),
    FOREIGN KEY (student_id) REFERENCES student(id)
);

-- 学习路径
CREATE TABLE learning_path (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL,
    path_json TEXT NOT NULL,         -- JSON: [{kp_id, order, reason}]
    status TEXT DEFAULT 'pending',   -- pending / approved / completed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    approved_at TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES student(id)
);

-- 每日统计（看板用）
CREATE TABLE daily_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL,
    date DATE NOT NULL,
    questions_answered INTEGER DEFAULT 0,
    correct_count INTEGER DEFAULT 0,
    total_time_minutes REAL DEFAULT 0.0,
    xp_earned INTEGER DEFAULT 0,
    UNIQUE(student_id, date),
    FOREIGN KEY (student_id) REFERENCES student(id)
);
```

## 4.3 完整 API 契约

### 通用响应格式
```json
{
  "success": true,
  "data": { ... },
  "error": null
}
```

### 诊断相关
```
POST /api/diagnose
  Request:  { "student_id": 1, "records": [{"kp_id": "K01", "is_correct": false}, ...] }
  Response: { "root_causes": [{"kp_id": "K01", "name": "有理数加法", "priority": 0.85, "reason": "..."}], "graph_snapshot": {...} }
```

### 练习相关
```
GET  /api/exercise/next?student_id=1&kp_id=K01
  Response: { "question": {...}, "options": [...], "session_xp_bonus": 15 }

POST /api/exercise/submit
  Request:  { "student_id": 1, "question_id": "Q001", "answer": "3/4", "time_spent": 45.2 }
  Response: { "is_correct": true, "xp_earned": 10, "streak_count": 5, "hint": null, "sprite_reaction": "happy_jump", "combo_milestone": null }
```

### 规划相关
```
POST /api/plan
  Request:  { "student_id": 1, "root_causes": [...], "parent_priority_overrides": {...} }
  Response: { "path": [{"order": 1, "kp_id": "K01", "name": "...", "reason": "..."}, ...], "estimated_sessions": 5 }
```

### 激励相关
```
GET  /api/sprite/state?student_id=1
  Response: { "stage": 2, "skin": "classic_gold", "evolution_progress": 0.65, "recent_achievements": [...] }

POST /api/sprite/customize
  Request:  { "student_id": 1, "skin": "deep_blue" }
  Response: { "success": true, "star_coins_remaining": 150 }

GET  /api/rewards/status?student_id=1
  Response: { "level": 5, "xp_current": 340, "xp_next": 500, "star_coins": 120, "daily_goal_progress": 0.8, "streak_days": 12, "unclaimed_achievements": [...] }

POST /api/rewards/claim
  Request:  { "student_id": 1, "achievement_key": "perfect_10" }
  Response: { "claimed": true, "reward": { "xp_bonus": 50, "star_coins": 10 } }
```

cd /opt/math-home-tutor/frontend

certbot --nginx -d <your-domain>

## 7.3 Nginx 配置要点
```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    root /opt/math-home-tutor/frontend/dist;
    index index.html;

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;
    }

    # PWA静态资源缓存
    location ~* \.(js|css|png|jpg|ico|svg|mp3)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```
